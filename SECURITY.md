# Política de segurança

## Versões suportadas

Apenas a versão publicada mais recente recebe correções de segurança.

## Relatando uma vulnerabilidade

Não abra uma issue pública com detalhes exploráveis. Use **Security → Advisories → New draft security advisory** no GitHub para enviar o relato de forma privada.

Inclua o impacto observado, passos mínimos de reprodução e, se possível, uma sugestão de correção. Evite acessar, alterar ou excluir dados que não sejam seus durante a pesquisa.
