# segurança

## versões suportadas

apenas a versão mais recente do projeto recebe correções de segurança.

## encontrou uma vulnerabilidade?

não abra uma issue pública com detalhes sensíveis.

use o recurso privado do github em:

**Security → Advisories → New draft security advisory**

inclua uma descrição do problema, como reproduzir e, se possível, uma sugestão de correção.
